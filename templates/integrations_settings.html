How integrations work

  • 1. Set API credentials as environment variables (in .env.local or your hosting platform)
  • 2. Map each integration to a lead source so imported data lands in the right channel
  • 3. GHL: "Sync Contacts" imports new contacts as CRM leads (skips duplicates via GHL ID)
  • 4. Meta Ads: "Sync Spend" pulls total ad spend for the current month into Channel Spend (creates or updates the entry)
